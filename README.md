# My First Project

My very first Java program, written at the start of my coding journey at **LTCA (Liftoff Tech Career Accelerator)**.

## About This Project

This project marks the beginning of learning Java — exploring variables, data types, and how Java programs are structured. It was the first step in building a foundation in object-oriented programming.

## What I Learned

- Setting up a Java project with **Maven**
- Declaring and using variables with different data types (`int`, `boolean`, `BigDecimal`, `String`)
- Understanding how the `main` method is the entry point of a Java program
- The difference between primitive types and reference types
- Using `BigDecimal` for precise decimal arithmetic (e.g., currency values like `4.99`)
- Basic class and object structure in Java

## Tech Stack

- **Java**
- **Maven**
- **IntelliJ IDEA**

## Key Concepts

| Concept | Description |
|---------|-------------|
| Variables | Storing values in named containers |
| Data Types | `int`, `boolean`, `BigDecimal`, `String` |
| `main` method | The entry point of every Java application |
| `BigDecimal` | Precise decimal math for financial values |
